Calendar feed
Subscribe once, then your calendar re-reads this file on its own. Adding, editing or removing a client here reaches every device the next time it refreshes.
Each time you update it
1. Tap Download renewals.ics above.
2. Upload it to your GitHub repo root, replacing the old file.
3. Nothing else. Subscribers pick it up within a day.
Subscribing, once per device
iPhone: Settings → Apps → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the URL.
Google Calendar: on desktop, Other calendars → + → From URL → paste.
